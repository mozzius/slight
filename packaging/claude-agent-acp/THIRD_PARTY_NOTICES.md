# Third-party notices: bundled Claude Agent ACP runtime

The shipped Slight host may bundle the target-specific runtime under
`claude-agent-acp/<target-triple>/`. The bundle contains the ACP adapter from
the Agent Client Protocol project, Anthropic's Claude Agent SDK and its native
platform runtime, their npm dependency graph, and Node.js. The generated
`NOTICE`, `licenses/`, and `bundle.json` files inside each bundle are the source
of truth for the exact versions and licenses shipped in that artifact.
